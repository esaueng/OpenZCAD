Union, Subtract and Intersect list their original bodies in pick order in
Options, with Base and Tool labels and a remove action for each. The live
guidance reads which originals the current Keep choice preserves. History
opens the same ordered list and persisted choice. The browser exercises Union
and Subtract on overlapping bodies, removes and restores the tool pick, and
checks result volumes at creation and body counts after a History edit
(`test/e2e/solid-result-options.spec.ts`).
