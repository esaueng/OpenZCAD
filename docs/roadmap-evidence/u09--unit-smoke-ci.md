Routine unit CI selects representative model, exact-kernel, command and web
editing/persistence cases while retaining workflow, privacy and package guards.
`pnpm test:full` retains the extended root/web regression suites. Selection
and fail-closed pre-worker Git preparation are covered by
`test/unit-suites.test.ts` and `test/unit-global-setup.test.ts`. This reduces
routine test breadth and does not claim additional product acceptance.
