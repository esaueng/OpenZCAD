Face Distance rebuilds use the historical rim interpretation for one-sided and
symmetric dimension edits. The parity fixture checks the original kernel’s
volumes on an imported beveled block. Saved Offset Face sets retain an exact
retry with their original rim interpretation, and old window-closing offsets
can still use the checked sweep after a collision. AI proposals leave an
ambiguous rim for the user to resolve in the Offset Face editor.
