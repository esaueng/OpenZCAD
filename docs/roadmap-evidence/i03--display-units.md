Delivered (schema v143, building on v141): switching an existing project's units without rewriting it. File › Units (mm, cm, m, in) and the palette's "Show lengths in …" commands set the document's `displayUnits` through one undoable, replayable, geometry-free `displayUnits.set` command; choosing the project's own unit clears it. Every stored length, persisted reference and export keeps reading `units`, so the model keeps its exact size and nothing rebuilds. Expression fields and the numeric keypad show and take plain numbers in the display unit and hand back stored-unit values (an untouched converted prefill commits the exact stored value); expressions keep their stored-unit meaning and preview in the display unit; sketch dimension labels (driving, and reference labels that follow the document), selection read-outs (lengths, Ø/R, areas, body size, the live diameter during a drag) and the measurement dock follow it. Older schemas refuse the field, its history changes and the command (`assertDisplayUnitsSchema`). Coverage: `test/display-units.test.ts`, `apps/web/src/components/displayUnits.test.tsx`, `apps/web/src/lib/sketch/dimensionAnnotations.test.ts`. Remaining: the explicit conversion of stored values (expressions, geometry, tolerances, ADR-013 witnesses) this row names, and the read-outs that still print stored units under their own label (Inspector property grids, status messages, drawing dimensions), and the parameter table, whose values keep their stored-unit meaning.
