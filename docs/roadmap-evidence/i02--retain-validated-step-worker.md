A first STEP import into an empty project can retain its cancellable validation worker for the committed broadcast. On the local 160-face hammer holder, the median first STEP download after import fell from 2,538 to 95 ms across three browser runs per revision, with identical STEP DATA. File selection through download fell from 7.37 to 5.03 s. Archived imports with a changed artifact ID still rebuild under their committed cache key.
