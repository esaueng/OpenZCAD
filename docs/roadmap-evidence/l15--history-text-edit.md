Slice B, history text edits: `compileHistoryEdit` diffs an edited history text against the document and compiles it into a `CadPatchProposal` (parameter set/rename/delete, feature rename/delete, new primitives, and three app- and agent-compiled operations kept out of the model's schema: `update_feature`, `reorder_feature`, `update_sketch_object`), which passes the assistant's parser, digest check and exact preflight and commits as one undo step; unchanged text compiles to nothing, and what the text does not edit (a kind, @metadata, a sketch's plane, drawing new sketch objects) is refused at its statement. The History as text dialog edits, checks (problems by line and column, changes listed) and applies through the app's own patch path with a version fence and a stale-edit banner; the agent API gains `get_history_text`, `preflight_history_text` and `apply_history_text`. Regression evidence: `packages/scripting/src/compile.test.ts`, `test/history-text-edit.test.ts` (an edited text applied on the exact kernel prints back as exactly that text, volumes follow, one undo restores the original text; a kernel refusal stops preflight), `packages/agent-api/src/agent-api.test.ts`, `HistoryTextDialog.test.tsx`, `describe.test.ts`.
