A persistent pattern relation that also holds instance positions (schema v145). Linear and Circular pattern now write one `pattern` relation per source instead of per-instance equal/parallel links: it names the source, each instance with its step, and the layout — the direction line and the spacing, or the pivot (a stored point: a circle's or arc's centre, a line or arc end, a sketch point), the step angle and Rotate or Uniform. On the solver each instance is stated against the source directly, with exactly its own freedoms: two for its anchor (a helper line from the source's anchor parallel to the direction at step × spacing; or from the pivot, as long as the source's and turned step × the step angle — the signed GCS angle), the rest for size and turn (equal length and the same or turned direction for a line, equal radius for a round, equal radius and turned or kept centre-to-end directions for an arc). So a pattern adds no freedom, moving or resizing the source carries every instance to its own step, and an instance moved alone conflicts. Deleting an instance leaves the others held at their own steps; deleting the source, the direction line or the pivot's owner removes the relation, and Trim/Extend drop the instance they reshape. Validation refuses mixed kinds, repeated entities or steps, a non-line direction and an invalid pivot. A circular pivot given only as coordinates keeps the earlier per-instance links. The relation is listed with the sketch's constraints ("Linear pattern 5 · Circle 1 ×3 along Line 1") and draws no glyph. Builds on v141 (#1911, on main); v142 to v144 are claimed by #1914, #1915 and the S07 entity lock (#1913). The solver's equations also admit mirror branches (a copy on the source's other side, a reversed line, the opposite ray from the pivot), so a solve starts each free instance at its step and reads every instance back against the source carried by its step, refusing a mirror by name; a uniform line pattern is carried by its midpoint, as the tool places it; trimming an instance into an arc keeps one relation; a pivot on a spline end is refused. Dragging or editing the source holds it where it was put and carries every instance with it (an edit whose free solve would undo a value the user set retries once with the edited entities held; a real conflict is still refused). Evidence: `test/sketch-pattern-relation.test.ts` (an edit moving the source carries each instance; a copy stays on its own side for either spacing sign and a wrong-side copy is refused; a uniform line keeps the tool's midpoint placement; a trimmed instance leaves one relation; a spline pivot is refused; on the pinned kernel: no added DOF; a moved, resized source carries each circle to its step; rotated and uniform line patterns follow a turned source to closed-form positions; a rotated arc pattern keeps radius and sweep at each 120° step; an instance pulled off its step conflicts; deleting one keeps the others at steps 2 and 3; the v144 refusal), `modify.test.ts`, `constraints.test.ts` and `test/e2e/sketch-modify-tools.spec.ts` ("dragging a linear pattern’s source carries every instance with it").
