A cylinder/block seam's two concave edges and adjoining convex top edge can
be selected in one fillet feature. Regression coverage checks all six
selection orders, material changes, one undo/redo step and the browser flow
(`mixed-seam-fillet.test.ts`, `mixed-seam-fillet.spec.ts`). Legacy planar-filter
counts no longer claim that untested edge subsets work or cannot be rounded.
The kernel uses its shared touching-feature cascade. The paired package also
enables display-only drag previews; the preview/checked-cache regression and
switch-scoping tests run in the routine unit selection with this kernel pin.
The kernel's approximation policy remains unchanged; general mixed corners
remain unqualified.
