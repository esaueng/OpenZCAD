Stored-unit conversion now accepts variable fillets, including per-corner radii (v151), in both mm→in and mm→cm. Oracle 2 refused them on area: the kernel measures B-spline face area by tessellating at a fixed 0.08 model-unit deflection, which isn't comparable across units, even re-measured in one kernel (7.4% apart for control nets equal to 3e-17). Such faces now leave the area total. Each one is matched one to one: the source body is serialized, scaled into the verification kernel, and must have the same NURBS structure with control points within kernel tolerance (a whole-surface bound), and each trimmed face must lie on the other at sampled points (`pointToFaceDistance`). A 1% end-radius or interior-station change is refused at 0.035 mm or 0.025 mm (`test/units-reference-recapture.test.ts`). The NURBS import still refuses on volume (`test/parity/unit-conversion.spec.ts`).
