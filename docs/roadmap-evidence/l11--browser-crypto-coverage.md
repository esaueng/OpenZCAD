Real-browser coverage for the E2EE packages, with Firefox added. `pnpm --filter @openzcad/mls test:browser` runs the MLS scenarios in a real module Worker in Chromium, WebKit and Firefox (61/61 steps in each; `-- --chromium-only` runs Chromium alone). New `pnpm --filter @openzcad/crypto test:browser` runs `packages/crypto/browser/scenarios.ts` (39 steps) on each engine's own WebCrypto and web streams in Chromium, WebKit and Firefox: chunked, incremental and streamed envelopes and content blobs (gzip and none, tampering, truncation, a gzip bomb); AES-KW and AES-GCM wraps, seal and open; project-envelope, version-chain, device-list, approval-grant and identity-transition signatures; the Phase 4-2 project data formats (`project-info` and `key-archive` envelopes with their body codecs, the epoch binding recomputed from a key archive, document-body revision hashes, the `rejoin-psk`, `archived-project-key` and `previous-account-key` wraps with every field bound, and `verifyVersionLog` / `verifyAuthoredLogRecord` refusing a rollback, a fork, a gap, a reorder, a falling epoch, a forged or unknown signer and a revoked device past its cutoff); the external-key seam; and the fixed vectors, the new ones included, byte-identical in every engine. AES-KW refusal is covered independently of the engine: all 11 KW purposes refuse a wrong parent key, another context and three flipped bytes on the engine as it is, and again with `crypto.subtle.unwrapKey` replaced by a stand-in that returns a zeroed key, each refusal following an unwrap that returned a key (the re-wrap check from #847). The one raw-WebCrypto step, an engine probe, reports a warning instead of failing when the engine skips the RFC 3394 integrity check; any other step that warns fails. Results on Windows (Playwright 1.63): Chromium 153 and Firefox 155 39/39 passed; WebKit 26.6 38 passed with 1 warning (its AES-KW unwrap returns zeroed keys), and the package refused all 55 bad unwraps there through the re-wrap check alone. `test/crypto-browser-scenarios.test.ts` runs every step in Node under `pnpm test` and requires that none warns. Both browser runs need `pnpm exec playwright install chromium webkit firefox` and stay out of `pnpm test` and CI.
