Orbit mode shortcut: Shift+O (remappable, "Toggle orbit mode") flips the orbit
preference between Free and Turntable from the workspace, as does the command
bar's "Orbit: switch to …" row. It changes the same account setting as
Settings → Controls → Orbit and says which mode is now on
(`apps/web/src/lib/keymap.ts`, `test/e2e/orbit-mode-setting.spec.ts`).
