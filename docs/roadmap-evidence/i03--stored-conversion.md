A project converts between mm, cm and inch, keeps its exact size, records one undo step and a "Before unit conversion" checkpoint, and refuses with the field named rather than mis-scale. Out of scope by decision: metres, custom-feature scripts and expressions that reach a length-discontinuous operation (`round(width)`). Still refused when they hold data: drawings, PMI, assemblies, reference images, growing-holder metadata, imported STEP raised lettering and per-end variable fillets. Not yet converted: saved views, the remembered section plane, the linear snap setting and comment pins.
