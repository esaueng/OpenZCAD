One guard, `assertPlaintextProject`, refuses every document, revision, measurement, view-state, artifact-list and room route of a format-2 project with 409 `PROJECT_FORMAT_UNSUPPORTED` ("This project is end-to-end encrypted. Update OpenZCAD to open it."), both inside the persistence methods and in a Worker gate every `/api/projects/:id` route meets before its handler; invitations, share links, invitation acceptance and member room tickets refuse with 409 `ENCRYPTED_PROJECT_SHARING_UNAVAILABLE`, existing share links serve nothing, listings build format-2 summaries from row columns only (placeholder name, no thumbnail, `storageFormat: 2`), and the assistant route refuses format-2 projects (decision D7).
