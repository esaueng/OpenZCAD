Exact export of any row ([design](docs/plans/configurations-design.md)): each configuration row has an Export picker (STEP, or the mesh dialog for 3MF, STL and the rest), available without edit access, and the mesh dialog names the configuration it writes with a picker to change it. A row that is not the one shown is built for the file alone from `documentForConfiguration`; nothing in the open document changes, and the file holds every body that row shows (the kernel adapter's new `documentExportBodyIds`, sharing `exportStepBodies`' choice of shown, unconsumed, unsuppressed bodies), so a row that suppresses a feature or shows a body the displayed row hides exports correctly. The printability check and the slicer hand-off use the same row, and the file is named after it. Evidence: `test/configuration-export.test.ts` (each row's body list, the hidden row's STEP re-imported as a 45 mm plate and tag without the lug, the displayed row unchanged, 3MF of the hidden row), `ExportDialog.test.tsx` and `ConfigurationTable.test.tsx` (the pickers), and `test/e2e/configuration-export.spec.ts` (STEP and 3MF of a row that is not shown, re-imported and measured, the model left as it was, and the dialog switched back to the shown row).
