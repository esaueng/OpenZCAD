Shell and draft publish verified lineage (QA 2026-11-14 finding #8). Both were hash-only, so every fillet or chamfer picked on a shelled or drafted body was a bare geometry hash: a Box height edit or a draft angle edit moved those edges and the plain rebuild refused with "A selected edge no longer exists" although the edge was still there. The #1330 carry rescues such picks only inside an edit's own commit, never across a draft angle, and never on a plain build. Shell now carries kept faces by exact witness or unique carrier, names the band on an opening's plane `shell.face.rim.*` and the wall one thickness inside a kept planar face `shell.face.inner.*` (either side tried; any second match leaves it unnamed). Draft carries undrafted faces and names a drafted planar face perpendicular to the pull `draft.face.*` only when exactly one result face lies on its plane turned about the neutral-plane hinge by the draft angle. Edges between two named faces take boundary roles. Shell → fillet survives Box height 30 → 40, and draft → fillet survives draft 2° → 3°/10°/30° and a Box height edit, each matching the part authored fresh (`test/shell-draft-edge-lineage.test.ts`). Parity corpus `shell-on-import` reference coverage 0 → 11 faces and 24 edges, with geometry and hashes unchanged. A refusal on an edited feature's card now names the later feature that lost its pick (`featureValidation.test.ts`). Open: non-planar shell/draft faces, drafts whose pull is not perpendicular to the face, and the QA's box-under-chamfer/fillet and early-chamfer-under-thread examples, which replay cleanly in independently authored models; their production projects were not available to identify the hash-only step.
