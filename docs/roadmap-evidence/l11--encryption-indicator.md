Phase 4, editor encryption indicator: an end-to-end encrypted project (the page's `isEncryptedProject` marker or a listed summary's `storageFormat` 2) shows a lock beside its name in the top bar; plaintext projects show nothing new, and with the E2EE flags off nothing changes. The lock opens a short popover with the state in plain words and a link to Settings › Encryption, and carries an optional `projectStateCode` slot for the Phase 5 project state code (unused until a build derives one). States come from a crypto-free subscription, `apps/web/src/lib/e2ee/encryptionStatus.ts` (in the entry chunk with no crypto import, like `unlockedKeys.ts`): verified (the last head this page opened or wrote — an account load or save, a new project or copy, a head the live room relays or accepts — passed verification; accessible name "End-to-end encrypted"), warning (a `stale-head` verification warning, kept until the project is switched away from), locked (`E2EE_KEYS_LOCKED` when the store opens; prompts to unlock in Settings › Encryption), problem (an `EncryptedProjectIntegrityError` in its own words, or the `repair` save state that halts autosave), and not verified yet before any of these. `encryptionStatusReports.ts`, loaded with the store by `encryptedProjects.ts`, reports each outcome for the key session that opened the store only; everything is forgotten on key-session teardown, and other projects' outcomes on a project switch. No migration, no flag change, no new dependency; the wording claims only what verification checks (signed by one of your devices, never moved back from a version this browser has seen). Evidence: `apps/web/src/components/TopBar.test.tsx` (each state, the repair override, the state-code slot, Escape, and a plaintext project showing nothing), `apps/web/src/lib/e2ee/encryptionStatus.test.ts` (warnings, integrity failures, locked keys, project switch, teardown reset but not on ready, the store wrapper on every head path and a late result after the session ended) and `test/e2e/encrypted-projects.spec.ts` (verified after create and after reopen from the account copy; absent for a plaintext project).
