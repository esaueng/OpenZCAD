Draft analysis overlay (view state only, no schema change): Display › Analysis › Draft colours every body on screen against a pull direction (±X/±Y/±Z) and a minimum draft: green drafts toward the pull, amber lies within ±minimum, red drafts away (an undercut against this pull), grey was not evaluated. It is one read-only query on the M09 clash query's worker path and build (`surface-analysis` request, `ExactKernelAdapter.surfaceAnalysis`, `packages/kernel-adapter/src/exact-surface-analysis.ts`), never the display mesh: each face is tessellated on its own, every vertex is projected onto the face's exact surface, and the kernel's `getFaceDraftAngle` gives the value there; a projection that lands off the tessellation by more than the chord tolerance leaves the sample unevaluated rather than coloured. The minimum only recolours (`draftBand`/`draftVerdict` in `@openzcad/shared`); a new pull measures again. The panel states its provenance (exact draft at samples; a plane's range is exact, a curved face's is its sampled range, with the count of exact face ranges) and its limits (not a parting-line or mouldability check; refused faces, partly evaluated faces, bodies over 150,000 samples and bodies with no exact geometry are listed by name, never given a value), and withholds the overlay while a preview stands in for the build. The overlay is a child of each body's mesh, so it follows assembly poses and the section cut, and is never picked; it is drawn as the body's faces (their material is switched off while it meshes every face, so the coarser samples are never hidden behind the finer display mesh), and the panel, colouring and overlay code load with the first analysis, outside the entry chunk. Evidence: `test/surface-analysis.test.ts` (box ±90°/0° exact with values matching the exact normals, a non-unit X pull, a cylinder wall at 0° sampled not exact, sphere halves crossing bands, a tilted body at ±30°/±60° where the build put it, a missing body, a zero pull refused), `packages/viewport/src/scene/analysisOverlay.test.ts`, `apps/web/src/lib/analysis/surfaceAnalysisUi.test.ts`, `AnalysisPanel.test.tsx`, `DisplayModeMenu.test.tsx` and the CI smoke case `test/e2e/analysis-overlays.spec.ts` (block and pin under +Z then +X, the legend recoloured at 5°, the overlay cleared on Turn off).
