Drawing properties and title-block fields (schema v70, built on v69 (M17 standard parts); [design](docs/plans/drawing-mvp-design.md#drawing-properties-and-title-block-fields-d02-schema-v70)): a sheet's `format` sets the units its dimensions print in (a millimetre model dimensioned in inches), the length and angle precision, decimal degrees or D°M'S", a decimal comma, and a print weight per line class; every dimension, callout and tolerance goes through one sheet number format, and the SVG and PDF writers read the sheet's weights before the ISO 128 defaults, so a sheet without a format exports byte-identical. The title block fills SIZE (`1:1 · A3`), UNITS (the printed units) and DATE (the latest saved revision's, until one is typed) automatically; title, scale and projection were already automatic. A content gate refuses `format` below v70. Evidence: `test/drawing-sheet-format.test.ts` (validation by name; inch, comma and D°M'S" text with carried seconds and dms tolerances; a 25.4 mm kernel box dimensioned `1 ±0.005` in inches; SVG/PDF weights, SIZE, UNITS and automatic/typed DATE; one undoable set/clear, replay, reload and the v69 gate), `DrawingWorkspace.test.tsx` (the panel writes one format, clears it when every field is default, refuses an out-of-bounds weight) and `test/e2e/drawing-properties.spec.ts` (a 38.1 mm box reads `1.5` then `1,5` in inches, SVG with the weight, units and size, reload).
