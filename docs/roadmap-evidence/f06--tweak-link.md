Tweak link that selects a row ([design](docs/plans/configurations-design.md)): a share link can name a configuration after its capability (`#share=<token>&configuration=<row id>`); only the row id travels, and its values come from the shared model, so a link can pick only a row its author defined. The shared model opens on that row (a row the model no longer has, or cannot take, opens it as saved and says so). Tweak gains a Configuration picker above the parameters, and switching rows is Tweak vocabulary like a value edit: allowed in a shared session and undone by Tweak's undo, while editing the table itself stays a Build edit. The sharing dialog's new link has an "Opens on" choice that rewrites the link before it is copied. Evidence: `test/project-share-link.test.ts` (reading, writing and replacing the row without disturbing plaintext or encrypted capabilities), `test/configurations.test.ts` (row switch is a Tweak command and Tweak-undoable, table edits are not; opening a shared model on a named, missing or unbuildable row), `TweakPanel.test.tsx` and `ProjectSharingDialog.test.tsx` (the picker and the Opens on choice), and `test/e2e/configuration-tweak-link.spec.ts` (a link naming Large opens on it, exports 3MF re-imported at 1808 mm³, switches to Small in Tweak and exports STL re-imported at 864 mm³, and undo returns to Large).
