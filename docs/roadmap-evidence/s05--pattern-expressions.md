Linear and circular sketch patterns keep the expression their spacing or
angle was typed with: a plain numeral still stores its number, an expression
stores the text (a linear extent and a circular total divided into steps as
the number was: `(E) / (count - 1)`, or `(E) / count` for a full turn), so a
parameter-driven pattern follows renames, F05 checks and re-evaluation; the
constraint list labels the evaluated value
(`test/sketch-pattern-expressions.test.ts`).
