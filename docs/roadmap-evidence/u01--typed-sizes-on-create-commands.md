Typed sizes on an armed in-place command reach its values instead of the view
shortcuts (2026-11-12 hands-on review): a digit, minus or point opens the
first value with a chip, Tab and Shift+Tab commit and step through the rest in
the order Options list them with the field held in one place, Enter commits
and returns focus to the command bar so the next Enter is Done, and a refused
or escaped entry restores the value. `B 100 Tab 60 Tab 6 Enter Enter` builds a
100 × 60 × 6 mm box where it used to turn the camera and end in "Box canceled";
Cylinder, Cone, Sphere and Torus share the path (`in-place-primitives.spec.ts`,
`NumericKeypad.test.tsx`, `exactEntryShortcut.test.ts`). A typed value that
takes a creation preview out of the clear stage reframes the camera onto the
created bodies, never for an edit or a drag (`fitFrame.test.ts`,
`docs/interaction-design.md`), and the command card keeps 12 px clear of the
view cube from 960 px to 1920 px wide.
