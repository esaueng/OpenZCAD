AI Assistant settings reserve the built-in model line and provider disclosure
area while server status loads, without showing fallback copy as a temporary
answer. An unreachable server retains its existing hint and generic disclosure.
The badge distinguishes an assistant switched Off from Ready or Unavailable;
the server's configured flag also incorporates the switch and account access,
so it does not mean only that a deployment model is missing. Happy-dom Settings
regressions cover loading, provider discovery, failure, and the badge states.
Account/auth resolving UI and application overlays are outside this slice.
