Slice 2, the compact frame behind a setting: Settings › Appearance › Layout (Automatic, Phone (preview), Full) is a per-device choice in `localStorage` (`openzcad.layout:v1`, never synced), resolved with the compact size class `(max-width: 600px), (max-height: 500px) and (orientation: landscape)` in `lib/layoutPreference.ts`; Automatic stays the regular workspace until slice 12 (`AUTOMATIC_RESOLVES_TO_COMPACT`). Compact renders through the same `AppShell` slots with `data-shell="compact"`: a lazily loaded header (back, name and save dot, command-bar search, overflow with Settings, Help and the File actions), mode tabs, floating undo/redo and selection chip, the view cube top-right, safe-area insets on all sides, and one `BottomSheet` (peek/half/full, back stack, focus trap over an inert stage at full, announced height, reduced-motion cross-fade) that holds the command card, the inspector, the in-place command bar and the phone lane's panel. The regular `panelLayout`/`panelState` are never stored from the compact workspace and come back untouched. `COMPACT_ENTRIES` names the undo/redo, mode, header, search, overflow and File entries. Evidence: `layoutPreference.test.ts`, `compact/BottomSheet.test.tsx`, `compact/CompactAppShell.test.tsx`, `test/e2e/compact-shell.spec.ts` at 390×844, 375×667, 360×640, 430×932 and 844×390 (frame fit, 44 px targets, mode tabs, Box to Done through the sheet with undo/redo, back to Full).
