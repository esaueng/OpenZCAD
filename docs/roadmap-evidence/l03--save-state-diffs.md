Slice 4, diffs between save states. Revisions › open a stored row › Compare opens "Compare “name”" with a choice of the project now or any other stored save point, and lists what changed in modelling terms: project name and units, features added, removed, renamed, suppressed or unsuppressed, edited, and a changed history order; parameters added, removed or re-expressed (`width: 20 → 35`); sketches (with their objects), bodies and drawing sheets. `diffSaveStates` (`packages/document-core/src/save-state-diff.ts`) is a pure function over two documents' canonical content: save points, revisions, the command log, undo history and meshes are left out, so a save compared with itself reads "No changes to the model". Both documents are read the way restore and preview read them (this device, then the account's trusted history, an ADR-024 historical read on an encrypted project) and compared in the browser; nothing is sent. Evidence: `test/save-state-diff.test.ts` (identical across a save point; added/renamed/suppressed/re-expressed and the reverse direction; an edited feature, a deletion with its body, a reorder and a project rename), `SaveStateCompareDialog.test.tsx` (wording, switching the comparison, an unreadable save), `RevisionsPanel.test.tsx` (Compare only for stored saves), and the CI smoke case `test/e2e/save-state-versions.spec.ts` (a saved box compared with the project after a cylinder: a feature and a body added, nothing changed by comparing).
