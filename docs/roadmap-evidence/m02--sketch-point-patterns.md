Slice 2, patterns driven by sketch points (schema v63, up from v62; no kernel change, Remus 2026.1.141). A `pattern` with `patternKind: 'points'` stores `points`: an earlier sketch, the I01 point entities it stands on, and the reference point the original stands on. Each other point takes a copy moved there from the reference. A copy's instance label is its point's id, so adding, removing or moving another point renames no copy, and `skippedInstances` names points. It works for whole bodies and, with `sourceFeatureIds`, for holes, bosses and cuts, so slice 1's per-copy proofs and refusals apply unchanged. Every copy is a rigid copy through the K05 copy-and-fuse path: the kernel has no entry point for an arbitrary set of translations, and copies that overlap are fused as any pattern's are. Validation refuses: points on another kind, a missing sketch or point, an entity that is not a point, a later sketch, a reference that is not one of the points, only the reference, skipping the reference, and skipping a point the pattern does not stand on. The build refuses a point deleted since by name, and a moved point carries its copy. A content gate refuses a v63 pattern on an older document.

UI (U11 pick-and-drag): a Point pattern tool in the Pattern group with the same Repeat option (Body, Features). After the body or the feature, clicks on the sketch's points (drawn as small crossed marks) choose where copies go. The tool, not the user, takes the reference: the sketch point nearest the original, and an edit keeps the one stored. Each copy wears the same skip chip where it lands. A History edit reopens with the points as picks and writes them back unchanged. The quick parameter preview leaves a pattern on points to the exact build, as slice 1 does for feature patterns and skipped copies.

Evidence: `test/point-pattern.test.ts` (14 cases: a hole repeated at four points with closed-form volume, bore axes and per-point copy names (`pattern.face.instance.<point id>.source.<hole feature id>.hole.face.bore`); a skipped point; a moved point carrying its copy; whole-body copies apart and overlapping, fused to 2500 mm³; a deleted point refused by name; points added through an edit; and the document and v63-gate refusals); `apps/web/src/lib/inPlace/tools.test.ts` and `edit.test.ts`; `test/e2e/point-pattern.spec.ts`, which drills a hole in place, picks its bore under Repeat Features, clicks two sketch points, skips one by its chip, and checks the stored pattern and its "1 skipped" History row.

Budget: the 10 × 10 grid preview (`node scripts/measure-active1-baselines.mjs --only pattern-node,pattern-browser`, 3 runs each) measured 7,571 ms in the browser and 7,645 ms in Node on this branch, against the 10,000 ms gate (slice 1: 7,550 and 7,631 ms; main before M02: 7,540 and 7,684 ms).

Open: path and mirror patterns; naming boss and cut copies' faces; repeating other feature kinds; a total-or-spacing choice for linear patterns.
