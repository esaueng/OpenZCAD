Two Command state gaps pinned by the U11 slice 2a coverage are fixed (Remus pin f210583ef8b4). A preview frame is the current request's only by its request generation, not its value key, so a value typed away and back (90°, 180°, 90°) waits for its own frame. A frame of a superseded request no longer sets or clears a refusal, takes the preview down, enables Done, or becomes or replaces the frame kept under a refusal (Fillet, Chamfer, Hole); one that built is still drawn while no refusal is shown, so a handle drag keeps following the hand, and a later refusal puts the last current frame back (`apps/web/src/hooks/useInPlaceCommand.ts`; `apps/web/src/hooks/useInPlaceCommandSuperseded.test.tsx`, both `it.fails` flipped, plus kept-fillet and typed-away-and-back cases). A Diameter or Radius of zero or less on a cylindrical wall is refused at the keypad field ("Diameter must be more than 0 mm.", an alert, `aria-invalid`, Apply held, Enter refused, never previewed) where it used to read as Ready and be dropped at Enter without a word (`radialSizeError` in `apps/web/src/lib/keypad.ts`; `keypad.test.ts`, `NumericKeypad.test.tsx`; `test/e2e/selection-preview-feedback.spec.ts` unpinned, with Radius starting from a fresh valid size).
