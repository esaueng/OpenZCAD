# Walkthrough

1. Start the app with `pnpm dev:web` and create a project on the start screen.
2. **Model**: add a box for the design space plus boxes for mounts/anchors, or import an STL.
3. **Preserve**: select the mount bodies and mark them preserve (green in the viewport).
4. **Constraints**: mark the anchor body fixed (blue); optionally mark keep-out obstacles (red).
5. **Loads**: select a body, enter force components in newtons, and apply (amber arrows).
6. **Study**: set the target volume fraction, objective, and resolution, then apply.
7. **Generate**: the checklist gates the run; generate mock outcomes.
8. **Results**: compare outcome cards, preview candidates in the viewport, export STL.
9. Save a revision from the top bar at any point; roles/loads/settings persist with the document.
