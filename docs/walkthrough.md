# Walkthrough

1. Start the app with `pnpm dev:web`.
2. Create a project from the command console.
3. Add primitives such as a box, cylinder, or sphere.
4. Add a sketch rectangle or circle and create an extrude feature.
5. Save a revision to the backend and reload the project list.
6. Import sample STL metadata or request an export job.
7. Inspect the model tree, properties panel, and viewport render output.
