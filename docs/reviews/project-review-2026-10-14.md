# OpenZCAD project review — 14 October 2026

**Base:** `main` at `ab3c1f1b` (PR #660), Remus pin `16371d5` (remus-wasm 2026.1.57, verified installed before any kernel repro; the worktree's stale `node_modules` held `f196856` and was reinstalled with `--frozen-lockfile` first).
**Method:** a local baseline of every CI gate, then eight parallel area reviews (document model, kernel boundary, viewport, cloud/security, import/export, performance, tests/tooling, UX in the browser). Every finding below is backed by a probe that fails on `ab3c1f1b`, a measured number with its method, or a recorded browser repro, and the lead re-ran every probe independently before accepting it. Findings already recorded in ROADMAP.md, the 1 and 11 October design reviews (F1–F30, G1–G16), the K02/L07/F05 audits or the production QA edge records are cited by ID rather than counted as new.
**Scope boundary:** local validation only. Nothing was deployed; no remote D1 migration was applied; `apple-silicon` was not dispatched; nothing was merged.

The worst problems are in persistence, not geometry:

1. **A large transaction makes a project unopenable** (DOC-1). Importing a STEP with 101 or more solids, or "Roll back after" with more than 100 later features, writes an undo entry the shared validator rejects. The project then fails to reopen on this device and every account save answers 400.
2. **Anonymous share links serve the owner's whole edit history** (DOC-2/SEC-2): deleted features, their dimensions, earlier parameter values, and the STEP source of an import deleted before sharing. The visitor's tab even loaded that history as its own undo stack; Tweak's guard kept the UI from replaying a non-parameter step, but the values were in the response for anyone to read.
3. **Mesh imports outgrow the document.** Each mesh is embedded in the feature node _and_ the command log, so a ~21k-triangle STL makes cloud save fail permanently while the status says "offline" (IO-2), a ≥100k-triangle import silently empties the undo stack (PERF-1), and trimming undo history to make room costs up to 6.4 s of main-thread time (DOC-4).
4. **STL import ignores project units since #353** (IO-1): a 25.4 mm cube lands as a 25.4-inch cube in an inch project.
5. **A `-0` coordinate raises a false "changed in two places" conflict** on every reopen (DOC-3).

Geometry correctness held up well: the same part built in mm, inch and metre documents gives identical volumes and STEP round trips, the rebuild-cache key covers units/parameters/suppression/import checksums, and the August claim that every commit retessellates the whole scene no longer holds. Access control on every Worker route also held (see "Checked and sound").

## Follow-ups found while reviewing the fix PRs

Both predate the review and behave the same on `ab3c1f1b`; they are recorded under ROADMAP F04.

- A mesh import whose file read is still pending when the user switches projects lands in the newly open project, for every mesh format. Refuse an import whose project changed mid-read.

## Checked and sound

- **Access control:** every non-public route authenticates first; roles come from D1 per request; no IDOR on project, revision, artifact, upload, measurement or workspace ids. The room strips client `x-openzcad-*` headers and rechecks membership on hello, presence, broadcast, write and lease; tickets are single-use, 30 s and project-bound.
- **Sign-in:** HMAC codes with constant-time compare and an atomic attempt limit; `__Host-` HttpOnly Secure SameSite=Lax cookie; same-origin checks on writes and upgrades; desktop PKCE with refresh-reuse revocation.
- **Data layer:** no string-built SQL; atomic quota triggers; no `CASE` in a trigger body (`d1-migration-split.test.ts` passes); bounded decompression; server-built R2 keys; AES-GCM personal tokens with random IVs; assistant permits released on error and cancel; CSP without inline script, framing blocked, API responses sandboxed and CORS-free.
- **Geometry and units:** identical mm³ volumes and STEP round trips for one part built in mm, inch and metre documents; exports scale to mm; DXF writes `$INSUNITS 4`; the rebuild key covers units, parameters, suppression and import checksums; pattern solid aliasing is guarded; stale broadcasts are gated.
- **Hostile files:** STEP (huge ids, self-references, 100k nesting, `1.E400`, UTF-16), GLB (2³¹ accessors, out-of-range strides, lying JSON length), PLY counts, a 3MF zip bomb and a 48 MB ASCII STL are refused or handled promptly.
- **Performance:** kernel cold load p50/p95 32.0/38.9 ms desktop (baseline 35.5/47.2) and 3,301/3,317 ms mobile-class; no WASM on the start screen; CAD operation harness early ≈ late at 100 features with 1–3 bodies remeasured per edit; hammer-holder warm edit 583 ms median.
- **Viewport:** overlay disposal across selection and rebuilds, StrictMode double mount, pick-list listener cleanup and hash-based topology ids all behave.
- **Tests:** all 773 tracked test files are collected by some runner; no `.only`/`.todo`/`.fixme`; no un-awaited `.rejects`; gating workflows have no `|| true` or `continue-on-error`.

## Recommendations for the unfixed items

1. **Mesh payloads live in the document twice (IO-2, PERF-1, PERF-2).** #673 only stops the refusal masquerading as "offline". A 25k-triangle STL — an ordinary 3D-print download — still keeps a project out of the account, its backup still fails to restore, and a 100k-triangle import still empties the undo stack. Recommendation: store imported mesh payloads content-addressed, exactly as STEP sources already are (blob store plus archived artifact, a SHA-256 reference in the node), keep `commandLog` entries by reference, and drop `commandLog` from the worker payload. Until that lands, warn at import time when the result would exceed the account ceiling. Effort M–L; it removes the largest remaining path to "my project never reached my account".
2. **A fillet on a sketch-extruded body freezes every earlier dimension (UX-1, K05).** This is the core parametric promise failing on the most common modeling sequence, and the Heat Sink demo advertises three parameters that always refuse. Recommendation: make region-extrude edge lineage plus v5 edge references for fillet/chamfer the next K05 slice. In the meantime (S): name the fillet in both refusal paths with Tweak-appropriate copy, and rebuild or relabel the Heat Sink parameters so the demo does not showcase a refusal.
3. **Two security findings stay open (SEC-3, SEC-4).** SEC-3 lets a third party disrupt a chosen account's sign-in; its fix is in progress in its own session and needs no migration. Schedule SEC-4 with L10: charging those tables to the owner needs a migration that must be applied to production D1 by hand before the Worker that relies on it ships.

Also worth a slot soon: the remaining KERN-1 gap (no timed retry for a source that fails while online), the CLAUDE.md CI drift (TEST-5) and a flaky-test budget for the e2e gate (TEST-7).
